OPERATING SYSTEMS PRACTICAL
MEMORY ALLOCATION: FIRST FIT, BEST FIT AND WORST FIT

1. Aim
To simulate dynamic memory allocation for a set of processes using First
Fit, Best Fit, and Worst Fit allocation algorithms.

2. Theory
Memory allocation is the process of assigning available memory blocks to
processes that request memory. In dynamic memory allocation, processes
are assigned memory from available free spaces according to an allocation
strategy.

This program accepts:
- Number of memory blocks.
- Size of each memory block.
- Number of processes.
- Memory required by each process.

Each algorithm is executed independently using the original block sizes.

3. First Fit
First Fit searches the memory blocks from the beginning and allocates a
process to the first block that has enough available space.

Steps:
1. Start searching from the first memory block.
2. Check whether the block has enough remaining space.
3. If it fits, allocate the process to that block.
4. Reduce the remaining space by the process size.
5. If no block fits, report that the process was not allocated.

Advantage:
- Simple and fast in many cases.

Disadvantage:
- Small unused holes may accumulate near the beginning of memory.

4. Best Fit
Best Fit searches all available blocks and selects the smallest block that
can accommodate the process.

Steps:
1. Check all memory blocks.
2. Find blocks whose remaining size is at least the process size.
3. Select the smallest suitable block.
4. Allocate the process and update the remaining space.
5. If no suitable block exists, report that the process was not allocated.

Advantage:
- Selects the closest suitable block and may reduce the immediate leftover.

Disadvantage:
- Requires searching all blocks and can create many small unusable holes.

5. Worst Fit
Worst Fit searches all available blocks and selects the largest block that
can accommodate the process.

Steps:
1. Check all memory blocks.
2. Find blocks whose remaining size is at least the process size.
3. Select the largest suitable block.
4. Allocate the process and update the remaining space.
5. If no suitable block exists, report that the process was not allocated.

Advantage:
- Leaves a relatively large remaining space in the selected block.

Disadvantage:
- May use large blocks for small processes and can waste large spaces.

6. Remaining Space
After allocating a process, the remaining space in its selected block is:

Remaining Space = Previous Block Space - Process Size

The output displays this remaining space for each allocated process. It is
the unused space left in that block after allocation.

Note:
In variable-sized dynamic partition allocation, this leftover is generally
called an external free hole or remaining free space, not internal
fragmentation. Internal fragmentation usually refers to unused space inside
an allocated fixed-size partition.

7. Comparison

First Fit:
- Selects the first suitable block.
- Usually requires less searching.
- May leave small holes near the beginning.

Best Fit:
- Selects the smallest suitable block.
- Searches all blocks.
- May create many small leftover holes.

Worst Fit:
- Selects the largest suitable block.
- Searches all blocks.
- Leaves the largest possible remainder in the chosen block.

8. Compilation and Execution
Save the source file as memory_allocation.cpp.

Compile:
   g++ -std=c++17 memory_allocation.cpp -o memory_allocation

Run:
   ./memory_allocation

9. Sample Input

5
100 500 200 300 600
4
212 417 112 426

10. Expected Output Format

For each algorithm, the program displays:
- Process No.
- Process Size.
- Block No. allocated.
- Remaining Space.

If a process cannot fit into any available block, the output displays
"Not allocated".

11. Viva Questions

Q1. What is memory allocation?
A. It is the process of assigning available memory space to processes.

Q2. What is First Fit?
A. It allocates a process to the first available block that is large enough.

Q3. What is Best Fit?
A. It allocates a process to the smallest available block that is large
   enough.

Q4. What is Worst Fit?
A. It allocates a process to the largest available block that is large
   enough.

Q5. Which algorithm searches for the smallest suitable block?
A. Best Fit.

Q6. Which algorithm searches for the largest suitable block?
A. Worst Fit.

Q7. What is fragmentation?
A. Fragmentation is memory wastage that occurs when memory is divided into
   spaces that cannot be used efficiently.

Q8. What is external fragmentation?
A. It occurs when free memory is divided into separate non-contiguous holes.

Q9. What is internal fragmentation?
A. It is unused space inside an allocated memory block or partition.

Q10. Does First Fit need to examine every block?
A. No. It stops at the first block that can accommodate the process.

Q11. Why are the algorithms run independently?
A. Each algorithm must start with the same original memory blocks so that
   their allocation results can be compared fairly.
