PAGING ARCHITECTURE CALCULATOR
Theory and Working

1. Introduction

Paging is a memory-management technique used by an operating system. It divides a process's logical memory into equal-sized blocks called pages. Physical memory is divided into blocks of the same size called frames. A page can be placed in any available frame, and a page table keeps track of the mapping between pages and frames.

2. Address structure

A logical address is divided into two parts:
- Page number: identifies which page is being accessed.
- Offset: identifies the exact byte within that page.

A physical address is also divided into two parts:
- Frame number: identifies the frame in physical memory.
- Offset: identifies the byte within that frame.

The offset has the same number of bits in both addresses because page size and frame size are equal.

3. Formulas used

Let:
LAS_bits = number of logical address bits
PAS_bits = number of physical address bits
Page_Size_bytes = page size in bytes

Offset bits (d) = log2(Page_Size_bytes)

Page number bits (p) = LAS_bits - d

Frame number bits (f) = PAS_bits - d

Logical address space = 2^LAS_bits bytes

Physical address space = 2^PAS_bits bytes

Total number of pages = 2^p

Total number of frames = 2^f

The page size must be a power of 2 so that the offset can be represented by a whole number of bits.

4. Explanation of the sample

Input:
Logical address bits = 32
Physical address bits = 26
Page size = 4096 bytes

Since 4096 = 2^12, the offset requires 12 bits.

Page number bits = 32 - 12 = 20 bits

Frame number bits = 26 - 12 = 14 bits

Logical address space = 2^32 bytes
                           = 4,294,967,296 bytes
                           = 4096 MB
                           = 4 GB

Physical address space = 2^26 bytes
                            = 67,108,864 bytes
                            = 64 MB

Total pages = 2^20 = 1,048,576

Total frames = 2^14 = 16,384

5. Program working

The C++ program asks the user to enter the logical address width, physical address width, and page size. It checks that the values are positive, that the page size is a power of 2, and that the address widths can accommodate the offset.

It then calculates the offset, page-number, and frame-number bit counts using the formulas above. The total address spaces are calculated using powers of 2. The number of pages and frames are also calculated using powers of 2. Finally, the program displays the results in a paging architecture report.

6. Conclusion

This program demonstrates how logical and physical addresses are divided in a paging system. It calculates the address-space sizes, offset bits, page-number bits, frame-number bits, and the total number of pages and frames from the three input values.
